📋 Terms & Conditions · Limitations ▼
1. Technical Ratings Only (Not Broker Analyst Ratings)
App లో Strong Buy / Buy / Neutral = technical rating మాత్రమే. Broker/analyst consensus, average target price, PE, PB, ROE, ROCE, Debt-to-Equity, quarterly results ఈ data source నుంచి రావు. Fundamentals weak అయినా technical signal strong గా వస్తే rating positive రావచ్చు.

2. Data Delay & Accuracy
Yahoo Finance data — real-time కాదు. 1–15 నిమిషాల delay ఉండొచ్చు. Volume data కొన్నిసార్లు incomplete / wrong గా రావచ్చు (especially low volume stocks).

3. False Signals Possible
Volume 2x spike అయినా price పైకి వెళ్లకపోవచ్చు. Market weak అయినా individual stock కి Strong Buy రావచ్చు. Overbought stocks కూడా Buy zone లో కనిపించే chance ఉంది.

4. Limited History (Fast Mode)
Fast mode లో 6 months data మాత్రమే. Long-term trend, major support/resistance సరిగ్గా కనిపించవు. Illiquid stocks లో signals unreliable.

5. No Automatic Risk Management
Position size, trailing SL, capital allocation మీరే చేయాలి. Gap risk / overnight risk కోసం automatic protection లేదు.

6. Journal cloud + local cache
Google login అయితే trades Firestoreలో. Local copy backup. Rules లేకుంటే API key ఉన్నవాడు రాయగలడు — consoleలో rules Publish చేయండి. Backup JSON కూడా ఉంచండి.

7. Single-file app
Source ఇప్పుడు 4 భాగాలు: src/styles.css · src/js/data.js · src/js/scorers.js · src/js/ui.js + src/shell.html. Phoneకి ఇచ్చేది ఇంకా ఒకే index.html — build.py కలుపుతుంది. file://లో వేరు JS load కాకపోవచ్చు, కాబట్టి delivery single file. Headerలో version చూసి overwrite చేయండి (—).

12. Firestore Security Rules (Firebase Console → Firestore → Rules → Publish)
Client PIN / email check = UX only. Real ACL = rules below. Lock is request.auth.uid == userId on the whole /users/{userId} tree, not only trades. Paste firestore.rules and Publish. Review deployed rules regularly.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
        && request.auth.uid == userId
        && request.auth.token.email == 'sriharshamsn05@gmail.com';
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
13. Local device risks
Journal/list localStorageలో ఉంటాయి — shared phone, stolen device, browser XSS, or backup apps can expose them. Prefer Google login + cloud; keep JSON backup offline. Do not rely on PIN.

14. Firebase config in source
apiKey is expected to be public in web apps; security is Rules + Auth, not hiding the key. Restrict Auth to your Google account in Console + rules above.
